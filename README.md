# LeafLens ML | Exploring Plant Disease Prediction with Python

A hands-on **Machine Learning workshop project** completed at **KLE's BCA College, Bailhongal**, focused on learning the fundamentals of **Python, Machine Learning, data analysis, and predictive modeling**.

This repository contains my Jupyter Notebook from the workshop, where I explored how Machine Learning can be applied to a real-world problem related to **plant disease prediction**.

## 📌 About the Workshop

The main goal of this workshop was to understand Machine Learning through practical implementation rather than only studying the theory.

During the workshop, I worked with a dataset, explored the data, performed basic data processing, and learned how Machine Learning models can be trained to identify patterns and make predictions.
